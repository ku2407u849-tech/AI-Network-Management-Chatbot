# AI Network Management Chatbot

## Introduction
This is a basic educational chatbot developed using Python and Streamlit.

## Features
- Answers networking questions
- Explains IP address, DNS, TCP and UDP
- Provides basic network troubleshooting information
- Simple chat interface

## Technologies Used
- Python
- Streamlit
- VS Code

## Installation

Install the required library:

pip install -r requirements.txt

## Run the Project

streamlit run app.py

## Working
The chatbot uses a predefined knowledge base and keyword matching
to provide answers to networking questions.
